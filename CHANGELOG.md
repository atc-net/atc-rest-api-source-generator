## [3.0.0](https://github.com/atc-net/atc-rest-api-source-generator/compare/v2.1.1...v3.0.0) (2026-10-27)


### ⚠ BREAKING CHANGES

* 3.0.0 changes the generated server, C# client and TypeScript client; what to change in a project is in Upgrading to v3 (https://github.com/atc-net/atc-rest-api-source-generator/wiki/Upgrading-to-v3).
* **server:** a line that set a switch for a feature the specification does not declare no longer compiles (it was a no-op); app.Use{Api}Api(...) is replaced by Map{Api}Api()'s ConfigureErrorHandling or app.UseGlobalErrorHandler(...).
* **server:** a form endpoint validates the request it builds as a JSON body of the same model is validated - the same keys, a registered validator for the model runs (Atc.Rest.MinimalApi's RequestValidation, with useValidationFilter); ATC_API_DEP013 and the CLI now require Atc.Rest.MinimalApi 3.1.0
* **server:** the host methods are named after the API, a specification secured with x-authorize-roles / x-authentication-required alone gets authentication in Map{Api}Api(), and the error handler can be left to the host
* such a property's type changes from Dictionary<string, object> to the typed dictionary.
* NotFound(), BadRequest(), TooManyRequests() and TooManyRequests(30) on a status whose specification declares a model without title, status or detail no longer compile; pass the declared model.
* 3.0 changes the error bodies the generated server sends, several generated client types and the TypeScript result unions, and pairs with Atc.Rest.MinimalApi 3.x - read https://github.com/atc-net/atc-rest-api-source-generator/wiki/Upgrading-to-v3 before updating.
